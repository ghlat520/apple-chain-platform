## 灵魂三问

### 1. 用户第一眼应该感受到什么？

- **扎根** — 像农业部的政务系统一样踏实、可信，不是互联网概念炒作
- **清澈** — 溯源码扫一下所有数据一目了然，没有灰色地带
- **温厚** — 农业产品的人情味，不冰冷，不高冷

**反检查**：
- ❌ 没有"现代/简约/高级"废话词 ✓
- ✓ 可视化：**扎根** = 暖米色底 + 无广告纯净版面；**清澈** = 大字号价格/时间/地点标签；**温厚** = 圆角 8px 非直角 + 绿叶点缀

---

### 2. 最不能违反的 5 条禁忌

1. **禁止使用高饱和度霓虹色**（紫/洋红/荧光绿等）
   - **为什么**：果农、合作社、监管官员审美偏保守；霓虹色让人联想到游戏/直播/电商营销，破坏政务可信度

2. **禁止使用深色背景模式作为默认**
   - **为什么**：户外果园强光下深色不可读；目标用户年龄段 35–60 岁对深色不适应；参考微信和支付宝一贯白底

3. **禁止彩色卡通插画 / 果农拟人化表情**
   - **为什么**：让平台显"初创感"和"玩票感"；真正的果农合作社会觉得"这不严肃"

4. **禁止交易产品式的红绿涨跌动画**
   - **为什么**：苹果产业链不是金融交易品；溯源/冷链/订单场景用涨跌色制造错误认知

5. **禁止密集的仪表盘 + 复杂筛选条（Bloomberg 风）**
   - **为什么**：目标用户主要单手竖屏操作（Vant 移动库证明了这一点）；桌面监管端才允许高密度，移动端必须疏朗

---

### 3. 视觉招牌菜

> **"政务系统级可信 + 果园清晨的暖光，一个苹果红圆点做品牌签名"**

对标参考融合：
- **温度**：Airbnb 的珊瑚红温暖感（食物 + 信任）
- **克制**：WeUI 的白底政务感（中老年用户友好）
- **可信**：Stripe 的网格精密（金融合规沿用过来）
- **灵魂标签**：苹果红 `#D32F2F` 作为唯一品牌点缀（产品叫"苹果"链，红苹果是最强记忆锚点）

## 内在张力

> **"像农业部的专业系统一样可信可查，但像微信一样果农一键就会用。"**

深层意思：对上（监管/政府/金融机构）要够严肃可审计；对下（果农/采购商/物流司机）要够简单能操作。两边用户的认知完全不同，视觉必须同时满足。

## 竞品定位地图

```
             [专业严肃]
                │
      金蝶政务  │   农业部大数据平台
                │
    ⭐          │
  apple-chain   │
                │
 ───────────────┼─────────────── [视觉温度]
     拼多多     │   淘宝助农
     果蔬电商   │
                │
                │
             [轻松亲民]
               冷 ← → 暖
```

- **Y 轴**：专业严肃 ↔ 轻松亲民
- **X 轴**：冷（数据密度/低温度）↔ 暖（人文/食物感）
- **apple-chain 位置**：偏暖（食物+人情味）但偏上（政务+金融合规）—— **左上象限的温暖版**

这个象限几乎没有竞品，是蓝海。

## 目标用户快照（6 角色 RBAC）

### Persona A — 果农 / 种植户（主画像 40%）
- **年龄**：40–60 岁
- **设备**：100% Android 手机（OPPO/vivo 为主）
- **场景**：果园户外强光、戴手套、手指粗糙、不戴老花镜
- **核心诉求**：扫码记录农事操作 / 查看今日天气预警 / 接收合作社通知
- **视觉约束**：**字号必须 ≥ 16px，触控目标 ≥ 48px，禁用手势操作**

### Persona B — 合作社 / 采购商（25%）
- **年龄**：28–45 岁
- **设备**：iOS 50% / Android 50%，偶尔用桌面
- **场景**：办公室 + 出差，手机桌面切换
- **核心诉求**：订单管理 / 供应商协调 / 库存查询 / 物流跟踪
- **视觉约束**：信息密度可偏高，但不能到交易终端程度

### Persona C — 冷链司机（10%）
- **年龄**：30–50 岁
- **设备**：Android 车载屏 / 手机
- **场景**：驾驶室强光 + 颠簸 + 戴眼镜
- **核心诉求**：温度监控 / 路线导航 / 到货签收
- **视觉约束**：**字号必须超大 18–20px，按钮必须 ≥ 56px，禁用小图标**

### Persona D — 平台管理员（10%）
- **设备**：桌面为主
- **场景**：办公室大屏，多窗口切换
- **核心诉求**：用户管理 / 角色权限 / 数据审计
- **视觉约束**：高密度、多 Tab、表格优先

### Persona E — 金融机构（10%）
- **设备**：桌面为主
- **场景**：银行风控室
- **核心诉求**：供应链金融审核、4 类金融产品查看
- **视觉约束**：政务系统风格，禁止互联网花哨

### Persona F — 监管 / 政府（5%）
- **设备**：政务内网桌面 / Pad
- **场景**：会议 + 现场检查
- **核心诉求**：溯源码扫描 / 合规审计 / 数据上报
- **视觉约束**：**最严肃**，禁止动效，禁止营销语言
